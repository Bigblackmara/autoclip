- Keep names, brand names and numbers.
- Do not add commentary, quotes, emoji or hashtags that are not in the original.
- If a line has nothing to convert, return it unchanged.

Respond with ONLY this JSON object, no prose and no markdown fences:

{"lines": ["first line", "second line"]}
